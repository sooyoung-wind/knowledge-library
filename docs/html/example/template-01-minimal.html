01배경 및 맥락

이 템플릿은 학술 보고서, 리서치 문서, 논문 요약에 최적화된 미니멀 레이아웃입니다. 가독성 연구에 따르면 본문 폰트 18px, line-height 1.75, 줄 길이 65ch가 장문 독서 최적 조건입니다.

연속되는 문단은 들여쓰기로 구분합니다. 이는 독자가 새 문단의 시작을 빈 줄 없이도 인식할 수 있게 해주며, 세로 공간을 절약합니다.

"Typography is the art and technique of arranging type to make written language legible, readable and appealing when displayed." — Robert Bringhurst, The Elements of Typographic Style

02핵심 발견

주요 수치

항목 권장값 근거
본문 폰트 크기16–18pxWCAG 2.1, Baymard Institute
행간 (line-height)1.5–1.75Nielsen Norman Group
줄 길이60–70chBringhurst, USWDS
문단 간격1.2emCSS Typography 가이드

주요 포인트

  • 폰트 크기보다 줄 간격과 여백이 가독성에 더 큰 영향을 미침
  • 한국어는 자모 밀도가 높아 Noto Serif KR 같은 전용 한국어 서체 사용 권장
  • 다크 모드에서는 순백(#fff) 대신 연회색(#E8E8E0)을 사용해 눈부심 방지
  • 단일 포인트 컬러로 링크·강조 요소를 통일하면 인지 부하 감소

03코드 예시

인라인 코드는 font-size: 0.83em 크기로 본문과 구분합니다.

/* 최적 가독성 CSS 기본값 */
body {
  font-size: 18px;
  line-height: 1.75;
  max-width: 65ch;
  color: #1A1A1A;
  font-family: 'Noto Serif KR', serif;
}

04결론 및 권고사항

이 섹션에 최종 결론과 독자를 위한 실행 가능한 권고사항을 작성합니다. 신뢰도 높은 발견을 우선 기술하고, 불확실한 영역은 명시적으로 한계를 밝힙니다.

  1. 폰트 크기와 줄 간격부터 올바르게 설정하세요
  2. 단일 포인트 컬러 시스템으로 일관성을 유지하세요
  3. 모바일에서 font-size: 16px이 최소 기준임을 기억하세요
  1. Bringhurst, R. (2004). The Elements of Typographic Style. Hartley & Marks.
  2. WCAG 2.1 Success Criterion 1.4.4: Resize text.
