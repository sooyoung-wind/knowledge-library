01 · Core Principles

가독성 핵심 원칙 7가지

WCAG 2.1, Nielsen Norman Group, Baymard Institute, 로버트 브링허스트의 연구를 종합하여 도출한 7가지 원칙입니다. 이 원칙은 세 개의 템플릿 모두에 공통으로 적용됩니다.

T
본문 크기
장문 독서는 18px, 대시보드·UI는 15–16px. 모바일은 16px 최소.
font-size: 17–18px
≡
줄 간격
NNG 연구: 1.5–1.75가 장문 독서 최적. 1.5 미만은 밀집감, 2.0 초과는 분절감.
line-height: 1.75
↔
줄 길이
WCAG 권장 45–85ch 내 65ch가 스위트스팟. 18px 기준 약 720px.
max-width: 65ch
◎
색상 대비
본문 최소 WCAG AA (4.5:1). 배경 #FAFAF8(따뜻한 흰) vs 순백 눈부심 차이.
#1A1A1A / #FAFAF8
A
폰트 수
최대 2–3종. Serif(본문) + Sans(UI) + Mono(코드). 그 이상은 인지 부하 증가.
Serif + Sans + Mono
◆
포인트 컬러
단일 강조색으로 링크·번호·마커 통일. 2색 이상이면 주의 분산.
--accent: 1 color
☽
다크 모드
prefers-color-scheme: dark 자동 적용. 다크 배경엔 순백 대신 #E8E8E0.
@media dark

03 · Decision Guide

어떤 템플릿을 선택할까?

문서의 목적·독자·내용 밀도에 따라 적합한 템플릿이 달라집니다.

상황 추천 이유
리서치 보고서, 논문 요약 T01 Minimal 장문 세리프 + 65ch가 집중 읽기 최적
학술 문서, 기술 명세 T01 Minimal 각주·인용·코드 블록 완비, 군더더기 없음
프로젝트 현황 보고 T02 Dashboard KPI 카드·배지·진행바로 상태 즉시 파악
기술 지표, 팀 모니터링 T02 Dashboard 사이드바 네비·데이터 테이블·타임라인
이그제큐티브 브리핑 T03 Editorial 굵은 헤드라인이 바쁜 의사결정자에게 최적
브랜드 보고서, 인사이트 T03 Editorial 풀블리드·2열이 잡지 수준 인상을 남김
혼합 (데이터 + 내러티브) T01 기반 +
T02 카드 차용		 T01 본문에 T02의 kpi-card·badge 클래스 복사 가능

04 · Customization

커스터마이징 가이드

세 템플릿 모두 :root의 CSS 변수만 수정하면 전체 스타일이 즉시 바뀝니다. 코드를 구석구석 뒤질 필요가 없습니다.

공통 CSS 변수

변수 기본값 설명
--accent 템플릿별 상이 포인트 컬러. 링크·번호·강조 요소에 전방위 적용
--text-primary #111 / #1A1A1A 헤딩·강조 텍스트
--text-secondary #555 / #475569 본문 텍스트
--bg #FAFAF8 배경색. 순백 대신 따뜻한 오프화이트 권장
--border #E5E5E0 구분선·카드 테두리
--max-width 720px 콘텐츠 최대 너비 (T01 전용)

브랜드 컬러 교체 예시

/* 카카오 스타일로 교체 */
:root {
  --accent: #3A1D1D;      /* 카카오 브라운 */
  --bg: #FEE500;          /* 카카오 옐로우 배경 — 단, 눈부심 주의 */
  --text-primary: #3A1D1D;
}

/* 그린 브랜드로 교체 */
:root {
  --accent: #059669;
  --bg: #F0FDF4;
  --text-primary: #064E3B;
}
체크포인트

포인트 컬러를 바꿀 때는 항상 WebAIM Contrast Checker로 배경 대비 4.5:1 이상인지 확인하세요. 배경이 밝은 경우 진한 컬러를, 배경이 어두운 경우 밝은 컬러를 선택합니다.

폰트 교체

Google Fonts의 @import URL만 바꾸면 됩니다.

/* 기본 (한국어 최적화) */
@import url('https://fonts.googleapis.com/css2?
  family=Noto+Serif+KR:wght@300;400;700&
  family=Noto+Sans+KR:wght@400;600;700&
  family=Fira+Code:wght@400;500&display=swap');

/* 영어 전용 대안 */
@import url('https://fonts.googleapis.com/css2?
  family=Merriweather:wght@300;400;700&
  family=Inter:wght@400;500;700&
  family=JetBrains+Mono&display=swap');
05 · Korean Optimization

한국어 환경 최적화

한국어 문서에는 영어와 다른 타이포그래피 고려사항이 있습니다.

폰트 선택 이유

  • Noto Serif KR — 장문 본문. 한글 자모 밀도에 최적화된 세리프 웨이트, 11,172자 완전 지원
  • Noto Sans KR — UI·헤딩·캡션. 화면 가독성과 작은 크기 선명도에서 우위
  • Fira Code — 코드 블록. 한국어 섞인 코드에서도 너비 일관성 유지

한국어 특이 사항

  • 자간(letter-spacing): 한글은 영어보다 자간 조정에 민감. 본문은 0~-0.01em, 헤딩만 -0.02em~-0.03em
  • word-break: keep-all을 설정하면 조사 단위로 줄바꿈 → 가독성 향상
  • 줄 길이: 65ch는 알파벳 기준. 한글은 한 글자가 넓어 실제 약 32–35자 → 충분히 적당
  • 이중 자간: 한글-영문 혼용 문장에서 영문은 살짝 작게(0.95em) 조정하면 시각적 균형 개선
/* 한국어 최적화 추가 설정 */
body {
  word-break: keep-all;          /* 조사 단위 줄바꿈 */
  overflow-wrap: break-word;     /* 긴 URL 등 강제 줄바꿈 */
  -webkit-font-smoothing: antialiased;  /* macOS 폰트 렌더링 */
}
06 · References

출처 및 근거

이 가이드의 수치와 권고사항은 다음 연구 및 문서를 기반으로 합니다.

  1. WCAG 2.1 Success Criterion 1.4.8 (Visual Presentation): 줄 길이 80ch 이하, 줄 간격 1.5 이상, 문단 간격 줄 간격의 1.5배 이상 권고.
  2. Nielsen Norman Group, Loranger, H. (2017). "Ideal line length for content." 50–75 characters per line.
  3. Baymard Institute: 본문 폰트 16–18px 권장, 모바일 16px 최소.
  4. Bringhurst, R. (2004). The Elements of Typographic Style (3rd ed.). Hartley & Marks. — 타이포그래피 황금률.
  5. U.S. Web Design System (USWDS): 콘텐츠 영역 60–70ch 권고.
  6. Google Fonts Knowledge: 한국어 웹폰트 최적화 가이드, Noto 폰트 패밀리 선택 기준.
  1. WCAG 2.1 SC 1.4.8은 AAA 레벨이지만, AA 레벨의 SC 1.4.4(텍스트 크기 조정)와 함께 적용 권장.
  2. NNG의 최적 줄 길이는 50–75자(영문 기준). 한국어는 글자 너비가 넓어 32–35자가 동일 효과.
  3. 다크 모드에서 순백(#FFFFFF) 배경에 흰 텍스트는 번짐 현상(halation)을 유발. #E8E8E0 권장.
